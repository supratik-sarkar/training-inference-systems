# Lineage & Provenance History: training-inference-systems

This repository represents the consolidation of historical graph acceleration and mixed-precision training research with modern Apple Silicon ML execution, parameter-efficient adaptation, and distributed training primitives. It is anchored directly on the genuine 2025 `gnn-mixed-precision` GitHub repository object.

## Provenance Model

* **2025 Historical Lineages**: Adaptive mixed-precision graph neural network execution (`legacy/gnn-mixed-precision/`) and push-pull graph batching (`legacy/gnn-push-pull/`), preserving genuine author dates, committer dates, commit messages, and tree states.
* **September 2026 Structural Migration**: Explicit migration boundary commit moving historical assets into `legacy/` and importing 2026 modern systems as independent Git histories via dual-parent merge commits.
* **2026 Modern Systems**: Production-grade Apple Silicon inference, parameter-efficient fine-tuning (LoRA), and distributed communication primitives developed and verified on Apple Silicon M4 Pro (macOS 15, Python 3.12.13).

No commits have been backdated, fabricated, or squashed. Historical chronology reflects genuine Git timestamps.
